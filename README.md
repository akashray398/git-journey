# Git Journey

A beginner-focused Git learning repository created to practice version control commands, PowerShell usage, and simple repository workflows on Windows.

## Overview

This project was created while learning the fundamentals of Git and GitHub. It includes sample files and notes used to practice important commands such as:

- `git init`
- `git clone`
- `git status`
- `git add`
- `git reset`
- `git commit`
- `git push`

The repository is intentionally simple and serves as a hands-on practice project for understanding how Git works in real life.

## Repository Structure

```text
git-journey/
├── .git
├── one.txt
├── two.txt
├── four.txt
├── myFolder/
│   ├── three.txt
│   └── gitMaster/
│       └── Git.txt
```

## Files Included

- `one.txt` – sample text file used for Git tracking practice
- `two.txt` – another file used during commit and status exercises
- `four.txt` – file created during learning and modification practice
- `myFolder/three.txt` – file inside a subfolder to practice nested directory tracking
- `myFolder/gitMaster/Git.txt` – detailed notes and step-by-step Git lesson guide

## Learning Goals

This repository helps practice:

- creating a local Git repository
- understanding the `.git` folder
- checking working tree status
- staging files for commit
- unstaging changes
- creating commits with meaningful messages
- working with tracked and untracked files
- handling subfolders and nested project files
- understanding Git basics before using GitHub professionally

## Common Git Commands Used

```bash
git init
git status
git add .
git add -A
git reset
git commit -m "Add initial files"
git push
```

## Notes

This is a personal learning project and not a production application. It is designed to reinforce Git basics and improve confidence with command-line version control workflows.
