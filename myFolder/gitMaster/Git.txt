56. VERY IMPORTANT DIFFERENCE: git reset

You encountered several forms.

A. Unstage changes
git reset

Usually means:

Remove changes from staging, but keep the actual file changes.

B. Move branch back one commit
git reset HEAD~

Means:

Move the current branch back one commit and keep the changes unstaged by default.

C. Dangerous working-tree reset
git reset --hard

Means:

Reset tracked files to the current commit and discard uncommitted changes.

Easy memory trick
git reset
        ↓
unstage

git reset HEAD~
        ↓
move branch back one commit

git reset --hard
        ↓
discard uncommitted tracked changes
57. GIT INTERVIEW QUESTIONS — BATCH 1
Q1. What is Git?

Answer:

Git is a distributed version control system used to track changes in files and collaborate on software projects.

Q2. What is GitHub?

Answer:

GitHub is a cloud-based platform that hosts Git repositories and provides collaboration features such as pull requests, issues, code review, and remote repository hosting.

Q3. What is the difference between Git and GitHub?

Answer:

Git     → Version control tool
GitHub  → Online platform for hosting/collaborating on Git repositories
Q4. What does git init do?

Answer:

It initializes a new Git repository in the current directory by creating Git's internal .git directory.

Q5. What does git clone do?

Answer:

It creates a local copy of an existing remote Git repository, including its Git history.

Q6. What is .git?

Answer:

.git is the hidden directory containing the Git repository's internal data, including history, objects, references, and configuration.

Q7. What is git status?

Answer:

It shows the current branch and the state of files, including staged, unstaged, modified, deleted, and untracked changes.

Q8. What does git add do?

Answer:

It places changes into the staging area so they can be included in the next commit.

Q9. Does git add create a commit?

Answer:

No.

git add     → staging
git commit  → creates commit
Q10. What does git commit do?

Answer:

It records the staged changes as a new commit in the local Git repository.

Q11. What does git push do?

Answer:

It sends local commits to a remote repository such as GitHub.

Q12. What is an untracked file?

Answer:

A file that exists in the working directory but is not currently tracked by Git.

Q13. What is a staged file?

Answer:

A changed file whose current changes have been added to the staging area and are ready to be included in the next commit.

Q14. What does git reset do?

Answer:

Its behavior depends on the options. With no commit specified, it is commonly used to unstage changes. Other forms can move the branch and, with --hard, discard working-tree changes.

Q15. What is the difference between git reset and git reset --hard?

Answer:

git reset
→ commonly unstages changes while keeping file changes

git reset --hard
→ resets staging and tracked working files to HEAD,
  discarding uncommitted changes
Q16. What does git branch development do?

Answer:

It creates a new branch named development but does not switch to it.

Q17. What does git checkout development do?

Answer:

It switches the working directory to the development branch.

Q18. What does * mean in git branch?

Example:

  development
* main

Answer:

The * indicates the currently checked-out branch.
